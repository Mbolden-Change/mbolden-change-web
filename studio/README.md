## Links to sections on the same page

1. Open the destination **Text & Media** block in the page’s Content list.
2. Set **Section ID** to a unique lowercase name with hyphens, such as `meeting-basic-needs`. Do not include `#`.
3. In the initiative card’s link, choose **Destination → Section on this page**.
4. Enter the **Label** and select the destination heading from the dropdown.

Only top-level Text & Media blocks with Section IDs appear in the picker. Duplicate IDs prevent publishing. If an ID changes or its section is removed, Studio flags links to that missing destination. Keep IDs stable after publishing because shared URLs may use them too.

For other destinations, choose **Page** to select a site document, or **External URL** to enter an address and choose the same tab or a new tab.
